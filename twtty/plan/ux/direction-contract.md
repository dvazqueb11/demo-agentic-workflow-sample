# Quiet Utility direction contract

**Decision:** Human User selected Quiet Utility on 2026-10-07.

## Intent

The product should feel composed, trustworthy, and useful before it feels technical. A quiet mineral canvas and disciplined cobalt accent make the shared task list easy to scan without imitating a generic SaaS dashboard.

## Visual system

| Dimension | Contract |
| --- | --- |
| Canvas | Soft mineral `#F3F4F2`; no gradients or decorative texture |
| Surfaces | White `#FFFFFF` with navy rules and restrained neutral borders |
| Type | Platform-native humanist sans; compact uppercase eyebrow only when it is not redundant with a heading |
| Ink | Deep navy `#17233B`; muted copy `#5E6879` |
| Accent | Cobalt `#2457D6`, reserved for primary action, focus, and selected filter |
| Status | Pine `#286746` for success; brick `#A43A2B` for destructive/error semantics |
| Spacing | 4-pixel base with a generous 24–40-pixel page rhythm |
| Shape | 10–14-pixel corners; controls remain rectangular and tactile |
| Depth | Borders first; one soft shadow only for the task composer and transient popovers |
| Motion | 120–180 ms opacity/transform feedback; disabled for reduced motion |

## Composition

- A narrow masthead establishes product name and shared-demo context.
- The task composer is the page's strongest object.
- Filters and item count form a compact utility row.
- Task rows use strong title alignment, persistent checkboxes, and one quiet action menu.
- Desktop content is a focused single column no wider than 880 pixels.
- Mobile collapses metadata before controls and keeps the add action visible without a floating button.

## Voice

Direct and specific: “Add task,” “3 open,” “Task deleted.” Avoid celebratory marketing copy, AI language, and technical workflow jargon.

## Prohibited drift

No gradients, glass effects, excessive pills, oversized display headlines, dashboard card grids, hidden core actions, color-only status, fabricated activity, or remediation controls in the product surface.
